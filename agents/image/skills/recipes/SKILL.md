# Recipes

Check `RECIPES.md` in this folder (or run `img recipes`) before building anything: if the ask matches a recipe,
follow it step by step. `img recipes` also prints your own recipes, `recipes.md` in your home (memory and data
folder). When you solve a new kind of ask well, add a recipe there (same format as `RECIPES.md`: the steps and exact
commands) so it's quick next time. `RECIPES.md` here is part of the package; you don't edit it.
