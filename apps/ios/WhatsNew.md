## 2.9.0

### zh-Hant

- 可以選擇分享使用分析，幫助我們改善 Codync：只記錄用了哪些功能，絕不收集訊息、程式碼或檔案，隨時能在設定關閉。
- 現在也能用 Windows 電腦執行你的 bot：在 Windows 安裝 Codync 後，用 iPhone 配對就能傳訊息、批准。

### en-US

- You can choose to share usage analytics to help improve Codync: only which features you use, never your messages, code or files. Turn it off anytime in Settings.
- Your bots can now run on a Windows PC too: install Codync there and pair your iPhone to message and approve them.
